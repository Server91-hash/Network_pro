# Network_pro
## Features - **IP information:** local IP, public IP, subnet mask, default gateway and MAC address - **Interface status:** connection state, speed, bytes sent/received, IPv4 and IPv6 -**Built-in tools:** Ping, Telnet ,DNS Lookup, Traceroute, Port Scan   and HTTP Test, each with live output and a Stop button - Auto-refreshes every few seconds
